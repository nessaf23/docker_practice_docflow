# Docker practice project
Система "DocFlow" — облачная платформа для управления электронным документооборотом в крупной организации. Сервис обрабатывает сканы документов (договоры, счета-фактуры, акты), которые сотрудники загружают через веб-интерфейс. Организация сталкивается с проблемой хранения и передачи больших объёмов сканированных документов. Исходные сканы высокого качества занимают на дисках много места и медленно загружаются через интернет. Требуется решение, которое автоматически оптимизирует изображения для экономии места и ускорения доступа, сохраняя при этом читаемость документов. 
Задача: настроить контейнерную инфраструктуру, обеспечить безопасность, производительность и надёжность работы системы, а также подготовить мониторинг для контроля ресурсов.

## Технологический стек
основные языки, фреймворки и библиотеки, использованные в проекте:
* **Backend:** python, http, Go
* **DevOps:** Docker
